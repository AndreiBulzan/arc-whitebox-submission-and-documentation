## What was genuinely new

The previously killed controls used an independent Gaussian/Price state or
a Procrustes-aligned covariance factor. R1 instead extracted the exact live
first spherical harmonic separately inside every complete antipodal basis.
For preactivation values at paired directions:

```text
even(u) = [z(u)+z(-u)]/2
odd(u)  = [z(u)-z(-u)]/2
g(u)    = mean(even) + odd(u).
```

Because one Kerdock block is a complete orthonormal basis, `odd(u)` is
exactly the sampled trace of a linear spherical harmonic. Its variance is
`mean(odd²)`, so the sphere integral of `ReLU(g)` and `ReLU(g)²` is analytic.
At every layer the cloud carried

```text
analytic integral of g
  + sample integral of [ReLU(z) - ReLU(g)],
```

then was affinely matched to the resulting first and second radial moments.
The closure therefore changed the state consumed at the next layer; this
was a true layerwise coupling, not an endpoint blend.

The unit gate confirms the intended identity. For a linear first
preactivation:

```text
surrogate maximum absolute error       0
first-harmonic residual RMS             0
recovered H1 mean maximum error         1.7881393e-7
```

All four K24 trajectories remained finite. Representative first-harmonic
residual RMS values were nonzero by layer 15 (`9.59e-4..1.16e-3`) and at
layer 31 (`2.60e-4..3.77e-4`), proving that the branch was exercising the
nonlinear residual rather than reproducing the direct estimator.

## Exact information learned

The first spherical harmonic is a useful control direction on Full, but it
does not explain the transferable quadrature error. The antithetic
decomposition localizes what remains:

- the odd/linear part is integrated analytically;
- the unresolved signal lies in the basis-varying even component and mixed
  higher angular harmonics;
- carrying only first/second moments of that residual through an affine
  state match does not preserve the required all-distinct connected signal.

This independently agrees with the connected-moment studies: a viable
`<=50B` method must expose at least a mixed quadratic/K3/K4 angular
observable. Another first-harmonic coefficient, checkpoint schedule, K
increment, or family-specific blend does not reopen this result.
