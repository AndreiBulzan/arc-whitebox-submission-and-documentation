# R87 residual-stack R1 preregistration

Date: 2026-08-08

## Objective and evidence boundary

Advance remote incumbent R87 / submission 324999 without changing its
estimator statistic.  This attempt evaluates two already-built but physically
unadjudicated execution surfaces on their frozen R81 parent, then composes
only a measured winner onto R87:

1. R82 straight-line K-wide bound executors;
2. R83 parent-identity-guarded persistent bind views.

No target, package upload, or remote submission is authorized.  A completed
local row is `measured whole`; any remote-score arithmetic is a `projection`.

## Prior-art preflight

Queries covered `straight-line`, `executor`, `persistent bind`, `view memo`,
`getitem`, `descriptor intern`, `R82`, `R83`, and the live R40 bind site.

Nearest controlled results:

- the global view memo is net-negative because it taxes every `__getitem__`;
- R78 descriptor interning is remote-proven and saves repeated descriptors
  within one bind;
- the owner census found 1,756 of 3,410 steady R40 bind views have persistent
  parent handles;
- R82 and R83 packages were built and hash-sealed but have zero setup and zero
  prediction receipts;
- R87 changes only the exact R40 factor schedule above R81, so these executor
  surfaces remain composable if their patch points are preserved.

Outcome: `materially new execution surface`.  R83 performs one parent-identity
check per bank at bind time and bypasses the killed per-view memo lookup.  R82
hoists Python loop control while preserving every remote operation, operand,
destination, order, and alias-retention point.

## Target ceiling

Remote R87 has raw MSE `2.2274112794207212e-7`, mean effective compute
`139.3650219275B`, and adjusted score `1.1433268804164358e-7`.

R78's remote transfer gives an empirical residual price of about 21
microseconds per removed steady request (`169` requests for `3.57ms` billed
residual).  Applied to R83's census ceiling of 1,756 reusable views, the
optimistic saving is about `3.69B`, or `2.65%` of R87 effective compute.  With
unchanged raw MSE that projects to roughly `1.1130e-7`.  The R82 range already
recorded in STATUS is another `0.2--1.2%`; it is tested independently because
the mechanisms can stack.

This ceiling is large enough to advance the banked score, though not by itself
to guarantee `1.10e-7`.  Therefore a physical gate is justified.

1. Run each exact existing archive through current FlopScope 0.10.0 /
   WhestBench 0.14.0 with bare setup, initialized Full0, and steady Full0.
2. Reject on any prediction-hash/count drift, lifecycle failure, cap failure,
   or nonpositive isolated effective-compute saving versus its exact R81
   parent.
3. If one or both pass, create a new capsule-native R87 descendant by applying
   only the winning class patch(es) while R87's frozen 74/53/142 schedule and
   live-unit partition are active.
4. Require exact initialized/steady R87 prediction hashes and counted ledgers.
5. Run an alternating quiet paired whole receipt against exact R87.  Promote
   only if median effective compute improves and wall remains safely below
   60 seconds.
6. Because the changes are intended to be prediction-identical, exact all-100
   Mini100 can be inherited only after output identity is proved over the
   complete changed execution path; otherwise rerun the exact archive gate.
